# Inter-Vlan-Routing-Router-On-A-Stick-
Implemented Inter-VLAN Routing using the **Router-on-a-Stick (ROAS) method** with IEEE 802.1Q encapsulation. Configured router subinterfaces and trunk links between two switches and a router to enable communication between VLAN 10 and VLAN 20 across both switches. Verified inter-VLAN connectivity using ICMP ping tests.
